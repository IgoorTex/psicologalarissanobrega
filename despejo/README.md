# Despejo — Larissa Nóbrega

Estrutura de pastas da landing page Despejo, dentro do repositório do site da Larissa.

| Caminho | Conteúdo previsto |
| --- | --- |
| `index.html` | Página do Despejo, quando a versão final for adicionada |
| `assets/images/` | Foto da Larissa, capas e outras imagens |
| `assets/videos/` | Os três vídeos otimizados para a página |
| `assets/css/` | Folhas de estilo externas, caso utilizadas |
| `assets/js/` | Scripts externos, caso utilizados |

Os arquivos `.gitkeep` mantêm as pastas visíveis no GitHub e podem ser removidos quando receberem os arquivos definitivos.

Esta etapa cria somente a organização de pastas. O HTML e as mídias do Despejo ainda precisam ser adicionados. O site principal permanece na raiz do repositório.
